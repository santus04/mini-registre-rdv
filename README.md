# Mini-registre de rendez-vous

Petite application web de gestion de rendez-vous, écrite en HTML, CSS et JavaScript pour apprendre le DevSecOps.

> **Attention :** n'utilisez que des données fictives. Les rendez-vous sont gardés dans le navigateur, sans chiffrement, et ne conviennent pas à de vraies informations de santé.

Site en ligne : https://santus04.github.io/mini-registre-rdv/

## Fonctionnalités

- Ajouter un rendez-vous (nom, date et motif), avec validation de la saisie.
- Supprimer un rendez-vous, en le retirant de l'écran et de la mémoire.
